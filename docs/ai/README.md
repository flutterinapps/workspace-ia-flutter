# Contexto bajo demanda

- `specs/<app>-<feature>.md`: spec de cada feature, escrita (o revisada) antes de
  codificar. La crea el agente `flutter-architect`.
- Decisiones de arquitectura (ADR): `adr/NNNN-titulo.md`, una por decisión.

Nada de aquí se carga siempre: el agente lo lee cuando la tarea lo pide.
